# 시각 언어 사양서 — 목표 화면

그래픽 품질의 **목표 기준**을 적어 둔 문서다. 무엇을 어떻게 그릴지 정하는 모든 작업(조명·연출·UI·CG·도트)은 여기 적힌 규칙을 따른다.
구현 방법이 아니라 **보이는 결과**를 규정한다.

기준은 2D 공포게임 플레이 영상 한 편을 보며 뽑아낸 연출 원리다.
참고용으로만 보았고 **그 게임의 그림·소리·글은 일절 쓰지 않는다**(영상 캡처도 저장소에 넣지 않는다). 아래는 관찰한 원리를 우리 말로 옮긴 것이다.

---

## 1. 화면 전체 (가장 중요)

지금 화면이 밋밋한 가장 큰 이유는 **빛이 원 하나뿐**이고 **화면 전체를 묶어 주는 처리가 없기** 때문이다.

| 규칙 | 내용 |
|---|---|
| V1 비네트 | 화면 네 모서리가 **뚜렷하게** 검게 떨어진다. 중앙만 보이고 가장자리는 거의 안 보일 정도로 강하게. |
| V2 색 통일 | 전체를 **채도 낮은 청회색**으로 눌러 톤을 묶는다. 그 위에 **빨강만** 포인트로 강하게 남긴다. 다른 색은 빛으로만 들어온다. |
| V3 암부 | 빛이 닿지 않는 곳은 "어두운 회색"이 아니라 **거의 검정**이어야 한다. 암부가 뜨면 싸구려로 보인다. |
| V4 입자감 | 아주 옅은 그레인(필름 노이즈)을 전면에 깔아 평평한 면을 없앤다. 눈에 띄면 과한 것이다. |

## 2. 조명

| 규칙 | 내용 |
|---|---|
| L1 방향성 광선 | 창문·천장등에서 **사다리꼴 광선**이 바닥에 비스듬히 떨어진다. 가장자리는 부드럽고 안쪽은 또렷하다. 원형 광원만으로는 절대 이 느낌이 안 난다. |
| L2 색 있는 빛 | 광원마다 색이 다르다. 형광등=청백, 비상등·유도등=녹색, 자판기=붉은 기, 달빛=푸른 기, 라이터=주황. |
| L3 빛의 경계 | 빛 웅덩이의 **가장자리가 보여야** 한다. 빛과 어둠의 대비가 화면을 만든다. |
| L4 위험의 색 | 위험 구역·사건에는 **붉은 안개가 화면 위에 반투명하게 덮인다**. 소프트한 덩어리 여럿이 느리게 흐른다. |
| L5 흔들림 | 형광등은 불규칙하게 깜빡이고, 불꽃 광원은 미세하게 밝기가 떨린다. 일정한 밝기는 죽은 화면이다. |

## 3. 서술(내레이션) 연출

조사·사건 서술은 **대화창을 쓰지 않는다**. 대사(인물이 말하는 것)와 서술을 시각적으로 분리한다.

| 규칙 | 내용 |
|---|---|
| N1 레터박스 | 위아래로 검은 띠가 들어오고, 화면 **가운데**에 흰 글자 1~2줄. 상자·테두리 없음. |
| N2 호(arc) | 검은 띠와 게임 화면이 만나는 경계에 **흰 호**가 완만하게 그어진다. 이 게임의 서명 같은 장식이다. |
| N3 괄호 | 특별히 무게를 싣는 줄은 『 』로 감싼다. |
| N4 들고남 | 띠가 위아래에서 밀고 들어왔다가 밀려 나간다. 툭 나타나지 않는다. |

## 4. 대사창

| 규칙 | 내용 |
|---|---|
| D1 이름표 | 말하는 사람 이름은 **빨간 테두리 판** 위에 올라간다. 판 아래쪽에 말풍선 꼬리가 달려 대사창을 가리킨다. |
| D2 초상화 | 초상화는 **대사창 위로 겹쳐 올라온다**. 대사창에 잘리지 않는다. 그래야 인물이 화면 안에 있는 느낌이 난다. |
| D3 등장 | 초상화는 바뀔 때 살짝 아래에서 올라오며 나타난다. 표정이 바뀌면 짧게 반응한다. |

## 5. 아이템 획득 · 알림

| 규칙 | 내용 |
|---|---|
| I1 배지 | 화면 가운데에 **큰 빨간 원 + 흰 아이콘**이 떠오르고, 아래에 획득 문구. |
| I2 리듬 | 원이 커지며 나타나 잠깐 멈췄다가 사라진다. 사라질 때 화면이 아주 살짝 밝아진다. |

## 6. 조사 지점 표시

| 규칙 | 내용 |
|---|---|
| E1 마커 | 조사할 수 있는 지점은 바닥·벽에 **작은 붉은 마름모**로 표시된다. 느리게 맥동한다. |
| E2 절제 | 화면에 여러 개가 동시에 떠서 지저분해지면 안 된다. 가까운 것만. |

## 7. 메뉴 · 타이틀

| 규칙 | 내용 |
|---|---|
| M1 배경 | 메뉴는 검은 판이 아니라 **키아트가 흐릿하게 깔린** 화면 위에 올라간다. |
| M2 네온 테두리 | 패널은 **빨간 네온 아웃라인**으로 그려진다. 면을 채우기보다 선으로 그린다. |
| M3 존재감 | 메뉴 화면에 **플레이어 캐릭터가 서 있다**. 메뉴가 게임 밖이 아니라 게임 안의 물건(휴대폰)처럼 느껴지게 한다. |
| M4 로고 | 타이틀 로고는 매끈하지 않다. 거친 질감·글리치가 들어간다. |

## 8. 캐릭터

| 규칙 | 내용 |
|---|---|
| C1 숨쉬기 | 서 있을 때도 **아주 미세하게 움직인다**. 완전히 정지한 캐릭터는 인형처럼 보인다. |
| C2 그림자 | 발밑 그림자는 빛의 세기에 따라 진해지고 옅어진다. |
| C3 림라이트 | 강한 광원 쪽 윤곽에 **밝은 테두리**가 생긴다. 라이터를 들었을 때 특히. |

## 지키는 선

- **조작성은 바꾸지 않는다.** 입력 매핑, 이동 감각, 버튼의 자리와 터치 영역, 조작 방식 설정 — 전부 그대로.
  버튼이 **보이는 모양**은 바꿔도 되지만 **있는 자리와 크기**는 그대로다. (`tests/controls.mjs`·`pad.mjs`·`mobile.mjs`·`landscape.mjs`가 좌표로 검사한다)
- **성능**: 저사양 안드로이드 기준. 프레임당 추가 비용이 눈에 띄면 되돌린다. 전면 효과는 반해상도·캐시를 우선한다.
- **외부 에셋·라이브러리를 늘리지 않는다.** 전부 코드로 그린다(캔버스·CSS·절차적 도트·WebGL).
