# 에셋 사양서 (Blender 렌더 스프라이트)

모든 스프라이트는 `tools/blender/common.py`의 3/4 탑뷰 정사영 카메라로 렌더한다.
게임 논리 해상도: 타일 가로 32px / 바닥 깊이 24px / 벽 정면 32px. 렌더는 2배(타일 64px).

## 좌표·앵커 규약 (반드시 지킬 것)

| 종류 | 지오메트리 위치 (Blender) | 앵커 `render_sprite(anchor=...)` | 게임에서 그리는 위치 |
|---|---|---|---|
| 바닥 타일 | x∈[0,1], y∈[-1,0], 윗면 z=0 (두께는 z<0 쪽 0.001 이하) | (0,-1,0) | 셀 남서쪽 모서리 |
| 벽/문 | x∈[0,1], y∈[-1,0], z∈[0, WALL_H≈1.512] | (0,-1,0) | 셀 남서쪽 모서리 |
| 바닥 소품 (w×h 셀) | x∈[0,w], y∈[-h,0] | (0,-h,0) | 발자국 남서쪽 모서리 |
| 벽걸이 소품 | 벽 셀(같은 셀) 남쪽 면 바로 앞: y∈[-1.06,-1.0], x∈[0,w] | (0,-1,0) | 벽 셀 남서쪽 모서리 |
| 캐릭터 | 발 중심이 원점, 키 1.25(학생)~1.3(어른) | (0,0,0) | 발 위치 |
| 아이템 아이콘 | 원점 중심 | (0,0,0), 고정 bounds 정사각 | UI 아이콘 |

- `+Y` = 북쪽(화면 위), `-Y` = 남쪽(카메라 쪽). 캐릭터 `down` = 카메라를 봄(-Y), `up` = 등(+Y), `right` = +X, `left` = -X.
- 같은 캐릭터의 모든 프레임은 **같은 bounds**로 렌더해서 크기/앵커가 흔들리지 않게 한다.
- 투명 배경(film_transparent). 캐릭터·소품 그림자는 엔진이 타원으로 그린다(바닥 그림자 렌더 불필요).
- 출력: `assets/sprites/<category>/<key>.png` + `write_meta('<category>', {key: meta})` → `assets/sprites/<category>.json`.
  메타 키 = 스프라이트 키, meta['file'] = `<category>/<key>.png`.
- 병합: `python3 tools/build_sprites.py` → `assets/sprites/sprites.json`.

## 스타일

- 저폴리 + 부드러운 셰이딩 + 작은 베벨. 2001년 한국 고등학교의 낡은 분위기. 채도 낮은 색.
- 조명은 common의 중립 조명 그대로(게임이 어둠/손전등을 덧입힌다). 너무 어둡게 렌더하지 말 것.
- 한글 글자가 필요하면 폰트 `/usr/share/fonts/truetype/wqy/wqy-zenhei.ttc`.
- 학생 교복: 남색 재킷, 흰 셔츠, 남학생 회색 바지·짙은 빨강 넥타이, 여학생 남색/회색 체크 치마·빨간 리본.
- 비율: 약간 데포르메(머리 큰 편, 머리:전신 ≈ 1:4). 얼굴은 단순(눈 두 점 정도), 머리 모양·색으로 구분.

## 카테고리별 목록

### tiles (바닥/벽/문)
- 바닥: `floor_corridor`(복도: 연녹회색 테라초/리놀륨, 미세한 줄눈), `floor_wood`(교실 마루, 세로 판재), `floor_tile`(화장실 흰 정사각 타일), `floor_stone`(현관: 회색 석재), `floor_stairs`(계단: 북쪽으로 올라가는 단 3개가 보이는 타일), `floor_metal`(환기구 내부: 아연 도금 철판, 리벳)
- 벽 정면 스타일 = 남쪽 바닥 종류에 따라:
  `wall_corridor`(위 크림색 회벽, 아래 1/3 진녹색 페인트 + 몰딩), `wall_wood`(교실: 위 미색, 아래 나무 징두리널), `wall_tile`(화장실: 흰 타일), `wall_vent`(환기구 내부: 철판 벽), `wall_top`(남쪽이 벽/바깥이라 정면이 안 보이는 경우: 윗면만 의미 있음, 정면은 어두운 회색)
- 창문 벽: `wall_window_corridor`, `wall_window_wood`, `wall_window_tile` (바깥 창: 정면에 큰 창, 유리 너머 짙은 남색 밤하늘)
- 복도-교실 사이 창: `wall_inner_window_corridor`, `wall_inner_window_wood` (정면 위쪽 절반에 작은 창 여러 개)
- 문 (벽 셀 크기와 동일, 닫힘/열림 쌍):
  `door_closed`/`door_open` (교실 미닫이 나무문, 위쪽 작은 유리창. 열림 = 문짝이 옆으로 밀려 문틀만 보이고 통로가 뚫림),
  `glassdoor`/`glassdoor_open` (현관·로비 이중 유리문, 금속 프레임),
  `metaldoor`/`metaldoor_open` (기계실습실/서무실 등 회색 철문),
  `shutter`/`shutter_open` (계단 방화 셔터: 가로 주름 철판. 열림 = 위로 말려 올라가 아래가 뚫림),
  `sealdoor`/`sealdoor_open` (결계문: 낡은 이중 나무문, 가운데 둥근 홈에 '木' 음각. 열림 = 활짝)

### chars_students (학생 4명) — 각 4방향 × 3프레임 = 12장

### tiles 추가분: 세로 벽(남북 방향 벽)에 끼는 문
카메라가 북쪽만 보므로 남북 방향 벽의 문은 정면이 보이지 않는다. 위에서 내려다본 모양이 문으로 읽히도록 별도 스프라이트를 둔다.
지오메트리·앵커는 벽 셀과 동일(x∈[0,1], y∈[-1,0], 앵커 (0,-1,0)).
- `door_v` / `door_v_open`: 닫힘 = 벽 높이보다 낮은(≈1.15) 나무 문짝이 셀 가운데 남북으로 서 있고 양옆(동서)으로 얇은 문틀, 윗면에 나무색이 보여 벽 윗면과 확연히 구분. 열림 = 문짝이 사라지고 문틀 기둥만 남아 바닥이 보임(통과 가능하게 보일 것).
- `glassdoor_v` / `glassdoor_v_open`: 같은 방식, 금속 프레임 유리문(중앙통로문).
- `metaldoor_v` / `metaldoor_v_open`: 같은 방식, 회색 철문.

### chars_others 추가분: 머리귀신
- `head_ghost`: 머리귀신. 몸 없이 바닥 위 약 0.3 높이에 떠 있는 사람 머리(시멘트 가루가 묻은 회색 피부, 헝클어진 검은 머리, 감기지 않은 흰 눈). 정면(카메라)을 향함. 발 위치 앵커 (0,0,0) = 머리 바로 아래 바닥. 단일 스프라이트.
