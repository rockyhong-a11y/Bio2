# QA 체크리스트 — 1장 수직 슬라이스

자동화(`node tests/run-all.mjs`)로 덮지 못하는 **실기기 항목**과, 자동화가 덮는 항목의 대응표입니다.

## 1. 실기기 필수 확인 (자동화 불가)

헤드리스 Chromium은 iOS Safari의 롱프레스 콜아웃·돋보기, 제스처 이벤트, 실제 손가락 핀치를 재현하지 못합니다.

| # | 기기/브라우저 | 절차 | 기대 결과 |
|---|---|---|---|
| M1 | iOS Safari | 타이틀 글자·대사창·버튼·게임 화면을 각각 1초 이상 길게 누름 | 텍스트 선택, 복사/공유 메뉴, 돋보기, 이미지 저장 메뉴가 뜨지 않음 |
| M2 | iOS Safari | 게임 화면 두 손가락 핀치 확대/축소 | 화면 배율 변화 없음 |
| M3 | iOS Safari | 아무 곳이나 빠르게 두 번 탭 | 더블탭 확대 없음 |
| M4 | Android Chrome / 삼성 인터넷 | M1~M3 반복 | 동일 |
| M5 | 공통 | 화면을 아래로 당김 | 당겨서 새로고침·바운스 스크롤 없음 |
| M6 | 공통 | 기기를 가로로 회전 | "세로로 돌려주세요" 안내, 다시 세로로 돌리면 정상 복귀 |
| M7 | 노치/홈바 기기 | HUD·메뉴 버튼·조사 버튼 위치 | 노치·홈 인디케이터에 가리지 않음(safe-area) |
| M8 | iOS 무음 모드 해제 | 타이틀에서 '새 게임' 탭 후 이동 | 발소리·사이렌 등 효과음 재생 |
| M9 | 공통 | 홈 화면에 추가 후 실행 | 주소창 없는 전체 화면, 세로 고정 |
| M10 | 저사양 안드로이드 | 2층 복도 달리기, 귀목 이벤트 | 끊김 체감 여부 기록(프레임 저하 시 보고) |

| G1 | 안드로이드 Chrome + 블루투스 패드 | 패드 연결 후 아무 버튼 → 화면 버튼이 숨고 안내 표시, 스틱 이동·A 조사·Y 휴대폰 | 반응함, 다시 화면 터치하면 화면 버튼 복귀 |
| G2 | iOS Safari + MFi/Xbox/PS 패드 | G1 반복 | 동일 (iOS는 페이지를 한 번 터치한 뒤 패드 입력이 인식될 수 있음) |
| G3 | PC Chrome/Edge + Xbox·PS 패드 | 타이틀부터 1장 끝까지 패드만으로 진행 | 대사·선택지·키패드·배전반·연타·메뉴 모두 패드로 조작 가능 |
| G4 | PC 키보드 | 방향키·Enter·Esc만으로 타이틀→메뉴→선택지 | 빨간 포커스 표시가 움직이고 Enter로 실행, Esc로 뒤로 |

## 2. 플레이 확인 항목 (수동 권장)

| # | 구간 | 확인 |
|---|---|---|
| P1 | 오프닝 | 현관문 잠김 → 목표 표시 "2층 2-8반…" |
| P2 | 2-6반 | 스위치로 불 켜기 전에는 교지가 반짝이지 않음 |
| P3 | 사이렌 | 경보 중 사이렌 반복음, 배전반 해결 후 멈춤 |
| P4 | 환기구 | 이동 속도 느려짐, 오른쪽 밸브는 왼쪽 밸브 후에만 도달 |
| P5 | 배전반 | 틀린 조합 시 불꽃 + 메모 힌트 안내 |
| P6 | 수위 추격 | 호루라기, 화면 가장자리 붉은 경고, 심장 박동음, 열쇠 소리 거리감 |
| P7 | 라이터 | 켜면 밝아지지만 수위가 더 멀리서 발견 |
| P8 | 숨기 | 화장실 칸 조사 → 숨음, 조사 버튼으로 나옴 |
| P9 | 머리귀신 | 한자리 70초 이상 머물면 종소리 → 출현, 계속 이동하면 흐려지며 사라짐 |
| P10 | 목매단 귀신 | 모퉁이에서 떨어져 기어 오다 멈추고 위층을 가리킨 뒤 사라짐(피해 없음), 장면 동안 수위 퇴장 |
| P11 | 귀목 | 7분 제한, 화분 3개 → 2-2반 나무 → 연타 QTE, 시간 초과 시 게임 오버 → '귀목 이벤트 직전부터 다시' 버튼 |
| P12 | 분기 | 방송실 선택지 8초 무응답 → A루트 |
| P13 | 저장 | 사인펜 0개일 때 저장 불가 안내, 귀목 제한시간 중 저장 거부 안내, 타이틀 '이어하기' 목록이 보이고 눌림 |
| P14 | 일시정지 | 제한시간·수위 추격 중 홈 버튼/앱 전환 후 복귀 → 시간이 흐르지 않았는지, 소리 재개 |
| P15 | 조작 | 조이스틱·조사·달리기·라이터·휴대폰 아이콘이 실제 손가락으로 반응(페이드 연출 직후 포함) |
| P16 | 컷신 | 주요 장면에서 위아래 검은 띠가 나오고 HUD·버튼이 숨었다가, 장면이 끝나면 돌아옴 |
| P17 | 초상화 | 화자가 바뀔 때만 초상화가 옆에서 밀려 들어오고, 같은 인물이 이어 말할 때는 깜빡이지 않음 |
| P20 | 자동 달리기 | 휴대폰 → 옵션 → 자동 달리기 켜기 → 조이스틱을 끝까지 밀면 달리고, 달리기(→'걷기') 버튼을 누르는 동안 걷기. 앱을 다시 열어도 유지. 조이스틱을 살짝만 밀면 걷기 |
| P21 | 전체 지도 | 지도 버튼(휴대폰 아래)·휴대폰 → 지도로 열기. 처음엔 1층만, 들어가 본 방만 밝고 나머지는 어두움, 잠긴 문(기계실습실 철문·방화 셔터·현관 등)은 빨간 선, 열쇠로 연 문은 빨간 선이 사라짐, 2층에 다녀오면 2층 지도도 나옴. 노란 점이 실제 위치와 맞는지 |
| P19 | 반응 초상화 | 물건 조사·잠긴 문·사건 서술 때 희민 초상화가 이름표 없이 나오고, 표정이 상황과 맞음(귀신·수위=겁먹음/놀람, 퍼즐·잠긴 문=결심/기본, 안도=미소) |
| P18 | 2D 그림 | 타이틀 배경(교문 너머 학교), 오프닝·金 문양·수위·목매단 귀신·귀목·녹음실(B루트)·결계문 CG가 각 장면에서 한 번씩 나오고 탭으로 넘어감. 표정이 대사 감정과 맞는지(소영 '…언니?' 슬픔 등) |
