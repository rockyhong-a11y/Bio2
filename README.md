# 화이트데이 탑뷰 (팬메이드 프로토타입)

「화이트데이: 학교라는 이름의 미궁」의 스토리를 따라가는 **모바일 세로 화면 전용 2D 탑뷰 어드벤처** 웹앱입니다.
현재 범위는 **제1장 · 본관 1구역 → 제2장 · 본관 2구역(土)** 이며, 1장 끝의 A루트(성아·지현)/B루트(소영) 분기를 이어 2장 土 결계문까지 완주할 수 있습니다(3장 「신관」은 준비 중).

> 비공식 팬 제작물입니다. 원작의 줄거리·인물·장소·사건 흐름을 따르되 **대사와 문서는 모두 새로 썼고**, 원작 에셋은 쓰지 않았습니다.
> 외부 공개·배포 전에는 원작 IP 권리 관계를 확인해 주세요.

## 플레이

**https://rockyhong-a11y.github.io/Bio2/** — 휴대폰 브라우저로 열어 주세요(세로 화면).

타이틀: **새 게임**(1장 처음부터) · **이어하기**(저장 3칸) · **챕터 선택** — 1장·2장은 바로 시작(2장은 루트 소영 / 성아·지현을 고르면 1장을 마친 상태로 시작: 라이터·사인펜 2개), 아직 없는 3장 신관(水)·4장 강당(火)은 딤드 '준비 중'으로 누를 수 없음.

배포: GitHub Pages가 `gh-pages` 브랜치를 그대로 서비스합니다. 갱신하려면 `git push origin <작업 브랜치>:gh-pages`.

## 실행 (로컬)

빌드 과정이 없는 정적 웹앱입니다.

```bash
npx http-server -c-1 -p 8080 .      # 또는 npm start
# 휴대폰에서 http://<PC IP>:8080 접속 (같은 Wi-Fi), 또는 GitHub Pages 등 정적 호스팅에 그대로 올리면 됩니다.
```

- 세로 화면 전용입니다. 가로로 돌리면 "세로로 돌려주세요" 안내가 나옵니다.
- 화면 길게 누르기(텍스트 선택·복사·돋보기·컨텍스트 메뉴)와 확대/축소(핀치·더블탭·Ctrl+휠)를 막았습니다.
- 홈 화면에 추가하면 전체 화면으로 실행됩니다(`manifest.webmanifest`).

## 1장 시스템

- **수위 이봉구**: 순찰 → 소리 확인 → 추격 → 수색. 손전등 시야(라이터를 켜면 더 멀리서 발견), 달리기 소음, 벽·문 시야 차단. 잡히면 1회 25 피해(4번이면 사망). 화장실 칸에 숨을 수 있지만 쫓기는 중 눈앞에서 숨으면 들킨다.
- **머리귀신**: 한 구역에 오래 머물면 종소리 4번 뒤 나타나 다가온다. 닿으면 피해 + 수위가 그 자리로 온다.
- **체력 회복**: 학교 동전 → 자판기 음료수.
- **저장**: 게시판에서 사인펜 1개를 써서 저장(3칸). 귀목 제한시간 중에는 저장할 수 없고, 대신 게임오버 시 '귀목 이벤트 직전부터 다시'를 고를 수 있다.
- **일시정지**: 다른 앱으로 전환하거나 가로로 돌리면 게임·제한시간·소리가 멈춘다.
- **퍼즐**: 배전반 스위치, 4자리 키패드(공구벨트·낙서 쪽지 번호는 플레이마다 무작위), 연타 QTE, 제한시간(귀목 7분), 시간 제한 선택지(루트 분기, 8초 무응답 시 A루트).
- **괴담 문서 수집**: 교지, 메모, 괴담 4편(휴대폰 → 문서에서 다시 읽기).
- **컷신**: 주요 장면(오프닝·성아/지현 만남·수위 등장·목매단 귀신·소영·방송실·결계문)은 위아래 검은 띠(레터박스) + 대화창 오른쪽 큰 초상화로 연출. 대사마다 표정(`놀람`·`슬픔`·`미소` 등)이 지정돼 있어, 힉스필드 2D 표정 초상화를 넣으면 자동으로 바뀐다.

## 2장 시스템 (본관 2구역, 土)

- **흐름**(`docs/story-bible.md` 2-01~2-12): 1장 결계문 → 1층 입구 → 상담실 조사 보고서 → 교무실1 분실물보관실 열쇠 → 2층 분실물보관실 흙인형 → 학생부실 칠판 수수께끼 → 교장실(서랍·숨은 모니터) → 교무실1 높은 캐비닛 위 제2교무실 열쇠 → 제2교무실 카세트·지현 → 3층 음악실 피아노 귀신·음악준비실 → 4층 미술실 가마 → 3층 과학실 개수대 → 아기 귀신 → 미술준비실 土의 패 → 2층 土 결계문.
- **동행 히로인**(B: 소영 / A: 지현, 성아는 따로 움직이다 마지막에 합류): 1~2칸 뒤에서 따라오고 층을 옮기면 곁에 나타난다. 닫힌 문은 열고 지나간 뒤 다시 닫는다.
  - **짜증**(숨은 수치 `strikes_<이름>`, 한 번마다 호감도 -1): 멀리 두고 감(6칸 넘게 3초) · 몸으로 계속 막음(2.5초) · 20초 안에 세 번 말 걸기 · 멀리 두고 계단 이동 · 앞장설 때 앞지름(B 2층 계단 이야기). 10초 쿨다운, 수위에게 쫓길 때는 면제. 말을 걸면 첫 번째는 지금 목표를 알려 준다.
- **수위**: 교장실 녹화를 보거나(또는 문을 열어 둔 채 서랍을 열어 들이닥치면) 그때부터 1층·4층 순찰. 아기 제한시간 동안은 사라지고, 土의 패를 주우면 2~4층에 다시 나타난다.
- **퍼즐**: 교장실 비밀번호({1,2,4,8} 순서 무작위, 칠판의 한자 빼기 네 줄 = 순서), 의자 밀기(조사 버튼 = 바라보는 쪽으로 한 칸, 막히면 원래 자리로), 피아노(숫자 악보 3·2·4·5·4 = 미레파솔파), 음악준비실 자물쇠(그림 조각 뒷면, 무작위), 가마 굽기(15초) → 5분 제한 → 세 번째 개수대 → 연타 QTE.
- **즉사·게임오버**: 완성된 인형 없이 아기에게 다가감, 5분 초과. 가마에서 꺼낼 때 체크포인트가 저장된다.
- **루트 차이**: B — 계단 이야기·소영 뒤 걷기, 지현은 따로, 도자기 회상(1998년 의식). A — 지현이 녹화 속 노랫소리에 홀려 사라졌다가 제2교무실에서 다시 합류, 회상 없음(일기만).
- 1장에서 라이터를 줍지 않았으면 2장 당직실에서 얻는다(학생부실 퍼즐에 필요).

## UI

적·흑 공포 테마(참조 스크린샷 기준): 빨간 테두리 대화창 + 이름표 + 오른쪽 큰 초상화(빨간 외곽선), 번개 아이콘 + 10칸 체력, 2001년 폴더폰 메뉴, 머리 위 빨간 **?** 말풍선, 연타 게이지(PRESS), 픽셀 글꼴 [갈무리](https://github.com/quiple/galmuri)(SIL OFL 1.1, `assets/fonts/OFL.md`).

## 에셋 파이프라인

- **도트 그래픽(현재 인게임)**: 배경과 캐릭터가 같은 픽셀 격자(게임 픽셀 1칸 = 도트 1칸, 화면은 최근접 확대).
  - 캐릭터: `python3 tools/pixel_chars.py [skin…]` (미리보기 `--preview 파일.png`) — 희민·소영·성아·지현은 컷신 초상화의 머리 모양·색·교복(남색 블레이저, 빨간 넥타이·리본)·안경·머리핀을 따름. 수위, 나영(기어 오기·목매단 모습), 머리 귀신 포함. 키 약 34px(32x48 프레임) — 문·책상과의 비율 때문에 기존 크기 유지
  - 바닥·벽·기존 소품·아이템: `python3 tools/pixelize.py` (원본 `art/render_src/`, 팔레트 `art/render_src/palette.png` 고정)
  - 원작 반영 소품·데칼: `python3 tools/pixel_props.py` — 공중전화(사다리 옆, 1-05), 태극기·급훈 액자 칠판, 소화전함, 비상구 표지, 학교 안내도, 포스터, 시간표, 라디에이터, 세면대, 우산꽂이, 쓰레기통, 청소함 / 바닥 얼룩·종이·금, 벽 금·얼룩(칸 좌표로 고정 배치)
  - 움직임(`js/ambient.js`): 형광등·자판기 불빛 깜빡임, 사이렌 회전등, 빛 속 먼지, 나방, 창문 빗줄기, 번개(실내가 잠깐 밝아짐)+천둥, 교실 커튼, 거미줄 거미, 로비 벽시계 초침, 공중전화 진동, 세면대 물방울, 쥐·바퀴벌레, 복도 끝 그림자(붉은 눈), 이상한 화분 떨림. 판정·충돌 없음
  - 다 고친 뒤 `python3 tools/build_sprites.py`
- **Blender**: `pip install bpy` 후 `python tools/blender/<카테고리>.py` → `assets/sprites/<카테고리>/*.png` 렌더, `python3 tools/build_sprites.py`로 병합.

  (희민 기본·놀람·미소·결심, 겁먹음은 당분간 놀람 그림 / 소영 5 / 성아 5 / 지현 4).
  시트 → 슬롯: `python3 tools/hf_sheet.py <시트> <슬롯1> <슬롯2> …` (배경 제거·칸 나누기·2배 확대) → `python3 tools/hf_import.py art/out/portrait_*.png`.
- **타이틀·CG 13장(현재 적용)**: SVG 벡터를 코드로 직접 그림(`art/cg`). 오프닝·金 문양·귀목·피아노 귀신 CG는 초상화 그림을 합성(`art/kit.js` `portraitIn`).
  2장: CCTV 녹화(`cg_cctv`)·피아노 귀신(`cg_piano`)·1998년 의식 회상(`cg_flashback`, B루트)·아기와 흙인형(`cg_baby`)·土 결계문 너머 통로(`cg_earth`).
  고치려면 `art/cg/*.js` 수정 → `node tools/render_art.mjs [슬롯…] --import`.
- **반응 초상화**: 조사·사건 서술마다 희민 초상화가 표정과 함께 나온다(`s.narrate(text, face)`, 이벤트 `face`, 잠긴 문 `lockedFace`).
- **힉스필드로 교체할 때**: `docs/higgsfield-prompts.md`(복사해 쓰는 완성 프롬프트)대로 만든 파일을 슬롯 이름으로 받아
  `python3 tools/hf_import.py <받은 파일들>` → 초록 배경 제거·크기 축소·WebP 변환·manifest 갱신, `node tests/hf.mjs`로 이름·투명 배경 검사.
  필수 26장 = 2D 애니메이션풍(미소녀·미소년, 고2) 초상화 18장(기본 4 + 표정 14) + 타이틀·CG 8장.
