「화이트데이: 학교라는 이름의 미궁」의 스토리를 따라가는 **모바일 2D 탑뷰 어드벤처**(세로·가로 모두, 자동 회전) 웹앱입니다.
현재 범위는 **제1장 · 본관 1구역 → 제2장 · 본관 2구역(土) → 제3장 · 신관(水) → 제4장 · 강당(火) → 제5장 · 미궁(B 루트)** 이며, 1장 끝의 A루트(성아·지현)/B루트(소영) 분기를 이어 **엔딩 8종**(하얀 국화·아이비·히아신스 / 튜베로즈·흑단목·민들레·접시꽃 / 사망 = 주목)까지 완주할 수 있습니다.

> 비공식 팬 제작물입니다. 원작의 줄거리·인물·장소·사건 흐름을 따르되 **대사와 문서는 모두 새로 썼고**, 원작 에셋은 쓰지 않았습니다.

## 조작

모바일 터치, PC 키보드, **게임패드(모바일·PC 공통, 표준 매핑 — Xbox/PS/스위치 프로 등)** 를 모두 지원합니다.
키보드나 패드를 누르면 화면 버튼이 숨고 버튼 안내가 나오며, 다시 화면을 터치하면 터치 조작으로 돌아갑니다.

**조작 방식(휴대폰 → 옵션 → 조작 방식, 이 기기에 저장)**
- **버추얼 패드**(기본): 왼쪽 아래를 끌어 이동, 오른쪽에 조사·라이터(라이터 그림) 버튼, 오른쪽 위에 휴대폰·지도 버튼. 버튼은 반투명이고 누르는 동안만 진해진다.
- **터치**: 화면 버튼 없음. 화면 어디든 끌면 이동, **탭 = 조사**(다음 탭을 0.3초 기다린 뒤), **두 번 탭 = 지도**, **세 번 탭 = 라이터**, **길게 누르기(0.6초) = 휴대폰**.

**달리기**는 따로 버튼이 없다: 조이스틱(스틱)을 **끝까지 밀면 달리기**, 덜 밀면 걷기(아주 살짝이면 더 천천히). 키보드 방향키·방향패드는 늘 달리기 — **키보드 Shift / 패드 RB**를 누르면 '걷기 고정'이 켜져 끝까지 밀어도 걷고, 다시 누르면 꺼진다. 달리면 발소리가 커서 수위가 듣는다. 2장에서 동행이 앞장서는 동안은 끝까지 밀어도 뒤에 붙어 걷는다(수위에게 쫓길 때는 달릴 수 있음).

터치 방식에서 대사·메뉴를 닫던 연타의 남은 탭(0.4초 안)은 무시한다(같은 대사가 다시 열리거나 지도·라이터가 켜지지 않게). 키보드·패드를 쓴 뒤에도 첫 터치가 바로 이동·탭이 된다.

## 1장 시스템

- **수위 이봉구**: 순찰 → 소리 확인 → 추격 → 수색. 손전등 시야(라이터를 켜면 더 멀리서 발견), 달리기 소음, 벽·문 시야 차단. 잡히면 1회 25 피해(4번이면 사망). 화장실 칸에 숨을 수 있지만 쫓기는 중 눈앞에서 숨으면 들킨다.
  가까워질수록 화면 가장자리가 **붉게 조여들고**, 그 위를 붉은 안개가 **심장 박동과 같은 박자**로 느리게 흐른다(불길이 번지는 4장 강당처럼 맵이 스스로 위험을 알리는 곳에서도 같은 연출).
- **머리귀신**: 한 구역에 오래 머물면 종소리 4번 뒤 나타나 다가온다. 닿으면 피해 + 수위가 그 자리로 온다.
- **체력 회복**: 학교 동전 → 자판기 음료수.
- **저장**: 게시판에서 사인펜 1개를 써서 저장(3칸). 귀목 제한시간 중에는 저장할 수 없고, 대신 게임오버 시 '귀목 이벤트 직전부터 다시'를 고를 수 있다.
- **일시정지**: 다른 앱으로 전환하면(화면이 가려지면) 게임·제한시간·소리가 멈춘다. 가로로 돌려도 멈추지 않는다.
- **퍼즐**: 배전반 스위치, 4자리 키패드(공구벨트·낙서 쪽지 번호는 플레이마다 무작위), 연타 QTE, 제한시간(귀목 7분), 시간 제한 선택지(루트 분기, 8초 무응답 시 A루트).
- **괴담 문서 수집**: 교지, 메모, 괴담 4편(휴대폰 → 문서에서 다시 읽기).
- **컷신**: 주요 장면(오프닝·성아/지현 만남·수위 등장·목매단 귀신·소영·방송실·결계문)은 위아래 검은 띠(레터박스) + 대화창 오른쪽 큰 초상화로 연출. 대사마다 표정(`놀람`·`슬픔`·`미소` 등)이 지정돼 있어, 힉스필드 2D 표정 초상화를 넣으면 자동으로 바뀐다.

## 2장 시스템 (본관 2구역, 土)

- **흐름**(`docs/story-bible.md` 2-01~2-12): 1장 결계문 → 1층 입구 → 상담실 조사 보고서 → 교무실1 분실물보관실 열쇠 → 2층 분실물보관실 흙인형 → 학생부실 칠판 수수께끼 → 교장실(서랍·숨은 모니터) → 교무실1 높은 캐비닛 위 제2교무실 열쇠 → 제2교무실 카세트·지현 → 3층 음악실 피아노 귀신·음악준비실 → 4층 미술실 가마 → 3층 과학실 개수대 → 아기 귀신 → 미술준비실 土의 패 → 2층 土 결계문.
- **동행 히로인**(B: 소영 / A: 지현, 성아는 따로 움직이다 마지막에 합류): 1~2칸 뒤에서 따라오고 층을 옮기면 곁에 나타난다. 닫힌 문은 열고 지나간 뒤 다시 닫는다.
  - **짜증**(숨은 수치 `strikes_<이름>`, 한 번마다 호감도 -1): 멀리 두고 감(6칸 넘게 3초) · 몸으로 계속 막음(2.5초) · 20초 안에 세 번 말 걸기 · 멀리 두고 계단 이동 · 앞장설 때 앞지름(B 2층 계단 이야기). 10초 쿨다운, 수위에게 쫓길 때는 면제. 말을 걸면 첫 번째는 지금 목표를 알려 준다.
- **수위**: 교장실 녹화를 보거나(또는 문을 열어 둔 채 서랍을 열어 들이닥치면) 그때부터 1층·4층 순찰. 아기 제한시간 동안은 사라지고, 土의 패를 주우면 2~4층에 다시 나타난다.

## 소리

**외부 음원 파일이 하나도 없다.** 효과음도 배경음악도 전부 WebAudio 로 합성한다(오실레이터·노이즈 버퍼·필터만).
기존 곡을 인용하지 않고 선법만 빌리므로 음원·악보 어느 쪽에도 저작권 문제가 없다 — `tests/sound.mjs` 가 음원 요청 0건을 검사한다.

**배경음악(`js/music.js`)**: 곡을 틀고 끄지 않는다. 지속되는 층 셋과 오르골 단음 스케줄러를 처음 한 번만 만들어 두고,
장면이 바뀌면 게인과 드론 기음만 미끄러뜨린다(노드를 다시 만드는 곳이 없다 — 지속 12개 고정).

| 층 | 내용 |
|---|---|
| 드론 | 3도가 없는 빈 5도 + 0.23% 디튠 맥놀이. 장면의 root(73~196Hz)를 따라간다 |
| 공기 | 기존 환경음을 대신한다. 밴드패스 중심이 40초 주기로 왕복, 긴장이 오르면 뒤로 물러난다 |
| 맥 | 긴장도 전용. 고Q 밴드패스로 금속을 긋는 '웅—'. 긴장 0.35부터 선형으로 올라온다 |
| 오르골 | 메나리토리 5음 중 랜덤 단음. 환기구·화재·게임오버에는 없다(없는 것이 연출) |

장면 8종(타이틀·본관·환기구·신관/강당·휴식·화재·미궁·게임오버)은 `mapId`·`flags`·`over` 에서 **매 프레임 다시 계산**한다.
그래서 체크포인트 복귀·불러오기·챕터 건너뛰기에 음악 복원 코드가 한 줄도 없다. 맵 데이터에서 바꾸고 싶으면 `def.music: '...'` 한 줄.
긴장도는 `g.danger`(경계 0~0.6 · 추격 1)를 그대로 받고, 제한시간과 **쫓아오지 않는 귀신**(거울 도플갱어·옥상 인어·아기)에 바닥값을 깐다.
올라갈 땐 0.25초로 컷처럼, 내려갈 땐 2.5초로 꼬리를 끈다. 컷신·메뉴·대사 중에는 버스를 45%로, 숨어 있는 동안은 30%로 줄인다.
소리 끄기·앱 전환은 버스가 `master` 아래에 있어 그대로 적용된다(**BGM 볼륨 옵션은 따로 두지 않는다**).

**효과음(`js/audio.js`)**: 40종. 자주 듣는 것과 헷갈리면 플레이가 꼬이는 것부터 손봤다 —
발소리는 매번 파형을 흔들고(같은 소리 반복 = 기계음), 심장 박동은 휴대폰 스피커가 실제로 내보내는 대역(150~500Hz)에 배음을 얹고,
문은 여닫이에 따라 쓸리는 방향이 반대이며(닫을 때 걸쇠 '딸깍'), **피격↔레버 · 스위치↔잠금해제 · 수위 열쇠↔쥐 울음**을 서로 반대 방향으로 벌렸다.
이름을 오타 내면 조용히 무음이 되던 구조라 `play()` 에 `default` 경고를 넣고, 데이터 전체의 효과음 이름을 테스트가 교차 검증한다.

## 복셀 연출

플레이어가 조작할 수 없는 **강제 연출 구간**(스크립트의 `s.cinema(true)` ~ `cinema(false)`)에서는
탑다운 화면 대신 **그 순간을 복셀 3D로 세워** 보여 준다. 기존 2D 컷신 그림(CG 29장)은 그대로 쓴다.

장면을 미리 만들어 두지 않는다 — **지금 월드에서 바로 세운다**. 벽·바닥은 맵 격자에서, 문·소품·인물은
기존 도트 스프라이트를 가로 런으로 묶어 밀어낸 판에서. 그래서 연출마다 따로 그려 둘 그림이 없고,
맵이나 스프라이트를 고치면 연출도 같이 따라온다. 인물은 움직이므로 1초에 10번 다시 세운다.

**공포는 카메라가 만든다.** 프리셋 8종을 구간마다 골라 쓴다 — `low`(발치에서 올려다보며 다가옴) ·
`loom`(덮쳐 옴) · `over`(위에서 내려다보며 멀어짐, 사람이 작아짐) · `dutch`(기울기가 커짐) ·
`push`(멈춰 있다 훅 다가감) · `arc`(대상 둘레를 96도 돎) · `close`(얼굴로 파고듦) · `wide`(넓은 공간이 조여듦).
컷마다 **지나가는 방식**이 다르다(`ease`: 끝에서 덮치는 `in`, 가라앉는 `out`, 지나쳤다 돌아오는 `swing`),
움직이기 전에 멈춰 있는 몫(`hold`), 손떨림 크기(`shake`), 그리고 **화각이 거리와 반대로 움직이는 돌리줌**
(`loom`: 거리 3.8→1.1칸인데 화각 70→88도 — 배경만 늘어나 멀미 나는 그 느낌).
카메라 **위치**는 대상 둘레의 (각도, 거리, 높이)로 잡고 **방향**은 대상을 똑바로 본 각에 기울기를 얹어 낸다
(절대 각으로 두면 대상이 화면 밖으로 나간다). 프리셋 방위가 벽에 막히면 **먼저 대상 둘레를 돌아**
트인 쪽을 찾고(한 칸짜리 복도에서는 물러설 수 있는 방향이 복도 축뿐이다), 그래도 막히면 대상 쪽으로
당긴 뒤 그만큼 **위로 올라가 내려다본다**. 벽은 2칸 높이까지만 있으므로 시야선이 그 위로 지나는 구간은
막지 않는다(높은 카메라가 괜히 당겨지지 않게). 카메라 코앞의 면은 버려서 벽 한 장이 화면을 덮지 않게 한다.

탑다운 스프라이트는 '남쪽에서 본 그림'이므로, 카메라 방위에 맞는 그림을 골라 **판을 카메라 쪽으로 세운다**.
앵커보다 **아래**에 있는 픽셀은 키가 아니라 보는 사람 쪽으로 퍼진 바닥이라(기어 오는 귀신의 몸통, 발밑 그림자)
세우지 않고 바닥에 눕힌다.

**해상도**: 버퍼는 화면 픽셀의 1/2 이고 **화면과 같은 비율**이다(아이폰 13 세로에서 390×664).
비율을 따로 묶으면 안 된다 — 예전에는 세로 상한(160) 때문에 1.6:1 그림을 0.59:1 화면에 늘려 그려서
인물이 세로로 네 배 뭉개졌다. 인물은 스프라이트를 1픽셀 단위로 복셀화하고(`STEP_CH=1`) 배경보다
1.5배 밝게 + 바닥값을 줘서 어두운 교복·머리가 벽과 붙어 보이지 않게 한다.

**성능**: Z버퍼 소프트웨어 래스터라이저로 그린 뒤 최근접 확대한다. 배경은 한 줄씩 `fill` 로 깔고,
무게중심 좌표는 픽셀마다 곱하지 않고 한 칸씩 더해 간다 — 이 둘 덕에 픽셀이 6배로 늘어도 비용은 2배만 는다.
실측 프레임당 중간값 6ms·최대 15.5ms(아이폰 13 세로 캔버스 기준), 면 1.4만 개 이하.
느린 기기에서는 프레임 시간을 보고 버퍼를 스스로 줄인다(최소 256폭).

`s.cinema(true, '프리셋', [칸x, 칸y])` — 프리셋을 안 주면 장면에서 고르고(쫓는 상대가 가까우면 `loom`,
다른 인물이 있으면 `dutch`, 없으면 `push`), 세 번째 인자로 **소품**을 대상으로 지정할 수 있다(결계문 등).
타이틀 → **갤러리 → 연출**에서 게임을 시작하지 않고 같은 화면을 다시 볼 수 있다(1~5장 46컷, `data/cinema.js`).
갤러리는 맵과 인물만 세우므로, 깃발로 켜지는 소품(불길·꺼진 불·쓰러진 인물·열린 셔터)은 각 항목의 `flags` 로 재현한다.
