# 화이트데이 탑뷰 (팬메이드 프로토타입)

「화이트데이: 학교라는 이름의 미궁」의 스토리를 따라가는 **모바일 세로 화면 전용 2D 탑뷰 어드벤처** 웹앱입니다.
현재 범위는 **제1장 · 본관 1구역(수직 슬라이스)** 이며, A루트(성아·지현)/B루트(소영) 분기까지 완주할 수 있습니다.

> 비공식 팬 제작물입니다. 원작의 줄거리·인물·장소·사건 흐름을 따르되 **대사와 문서는 모두 새로 썼고**, 원작 에셋은 쓰지 않았습니다.
> 외부 공개·배포 전에는 원작 IP 권리 관계를 확인해 주세요.

## 플레이

**https://rockyhong-a11y.github.io/Bio2/** — 휴대폰 브라우저로 열어 주세요(세로 화면).

배포: GitHub Pages가 `gh-pages` 브랜치를 그대로 서비스합니다. 갱신하려면 `git push origin <작업 브랜치>:gh-pages`.

## 실행 (로컬)

빌드 과정이 없는 정적 웹앱입니다.

```bash
npx http-server -c-1 -p 8080 .      # 또는 npm start
# 휴대폰에서 http://<PC IP>:8080 접속 (같은 Wi-Fi), 또는 GitHub Pages 등 정적 호스팅에 그대로 올리면 됩니다.
```

- 세로 화면 전용입니다. 가로로 돌리면 "세로로 돌려주세요" 안내가 나옵니다.
- 화면 길게 누르기(텍스트 선택·복사·돋보기·컨텍스트 메뉴)와 확대/축소(핀치·더블탭·Ctrl+휠)를 막았습니다.
- 홈 화면에 추가하면 전체 화면으로 실행됩니다(`manifest.webmanifest`).

## 조작

모바일 터치, PC 키보드, **게임패드(모바일·PC 공통, 표준 매핑 — Xbox/PS/스위치 프로 등)** 를 모두 지원합니다.
키보드나 패드를 누르면 화면 버튼이 숨고 버튼 안내가 나오며, 다시 화면을 터치하면 터치 조작으로 돌아갑니다.

| 모바일 | 키보드 | 게임패드 | 기능 |
|---|---|---|---|
| 왼쪽 아래 아무 곳 드래그 | WASD / 방향키 | 왼쪽 스틱 / 방향패드 | 이동 (가상 조이스틱) |
| 조사 | Space / Enter / Z | A | 앞에 있는 것 조사·문 열기·숨기 (조사할 게 있으면 머리 위 빨간 **?**, 사람은 **…**) |
| 달리기 (누르고 있기) | Shift / X | B / RB / RT (누르고 있기) | 달리기 — 소리가 커서 수위가 듣는다 |
| 불꽃 아이콘 | L / F | X | 라이터 켜고 끄기 — 밝지만 수위 눈에 잘 띈다 |
| 오른쪽 위 휴대폰 | Esc / M | Y / Start | 휴대폰 메뉴: 소지품·문서·목표·저장 안내·옵션·종료 |
| 화면 탭 | 방향키 + Enter, Esc 뒤로 | 방향패드 + A, B 뒤로 | 대사 넘기기, 선택지·키패드·메뉴 고르기, 연타 |

## 1장 시스템

- **수위 이봉구**: 순찰 → 소리 확인 → 추격 → 수색. 손전등 시야(라이터를 켜면 더 멀리서 발견), 달리기 소음, 벽·문 시야 차단. 잡히면 1회 25 피해(4번이면 사망). 화장실 칸에 숨을 수 있지만 쫓기는 중 눈앞에서 숨으면 들킨다.
- **머리귀신**: 한 구역에 오래 머물면 종소리 4번 뒤 나타나 다가온다. 닿으면 피해 + 수위가 그 자리로 온다.
- **체력 회복**: 학교 동전 → 자판기 음료수.
- **저장**: 게시판에서 사인펜 1개를 써서 저장(3칸). 귀목 제한시간 중에는 저장할 수 없고, 대신 게임오버 시 '귀목 이벤트 직전부터 다시'를 고를 수 있다.
- **일시정지**: 다른 앱으로 전환하거나 가로로 돌리면 게임·제한시간·소리가 멈춘다.
- **퍼즐**: 배전반 스위치, 4자리 키패드(공구벨트·낙서 쪽지 번호는 플레이마다 무작위), 연타 QTE, 제한시간(귀목 7분), 시간 제한 선택지(루트 분기, 8초 무응답 시 A루트).
- **괴담 문서 수집**: 교지, 메모, 괴담 4편(휴대폰 → 문서에서 다시 읽기).
- **컷신**: 주요 장면(오프닝·성아/지현 만남·수위 등장·목매단 귀신·소영·방송실·결계문)은 위아래 검은 띠(레터박스) + 대화창 오른쪽 큰 초상화로 연출. 대사마다 표정(`놀람`·`슬픔`·`미소` 등)이 지정돼 있어, 힉스필드 2D 표정 초상화를 넣으면 자동으로 바뀐다.

## UI

적·흑 공포 테마(참조 스크린샷 기준): 빨간 테두리 대화창 + 이름표 + 오른쪽 큰 초상화(빨간 외곽선), 번개 아이콘 + 10칸 체력, 2001년 폴더폰 메뉴, 머리 위 빨간 **?** 말풍선, 연타 게이지(PRESS), 픽셀 글꼴 [갈무리](https://github.com/quiple/galmuri)(SIL OFL 1.1, `assets/fonts/OFL.md`).

## 폴더

```
index.html, css/, js/          게임 엔진 (Canvas 2D + DOM UI, 외부 라이브러리 없음)
data/chapter1.js               1장 맵·아이템·문서·이벤트 스크립트
assets/sprites/                Blender 렌더 스프라이트 + sprites.json
assets/hf/                     힉스필드 결과물 슬롯 (2D 표정 초상화·CG·타이틀)
assets/fonts/                  갈무리 픽셀 글꼴 + 라이선스
tools/blender/*.py             Blender(bpy) 모델링·렌더 스크립트
tools/build_sprites.py         스프라이트 메타 병합 + 힉스필드 목록 갱신
tools/hf_key.py                힉스필드 초상화 초록 배경 → 투명 PNG
tests/                         QA 자동화 (Playwright)
docs/story-bible.md            원작 조사 정리(출처 신뢰도 표기) — 각색 기준 문서
docs/asset-spec.md             에셋 사양(좌표·앵커·목록)
docs/higgsfield-prompts.md     힉스필드 프롬프트 시트·파일명 규칙
```

## 에셋 파이프라인

- **Blender**: `pip install bpy` 후 `python tools/blender/<카테고리>.py` → `assets/sprites/<카테고리>/*.png` 렌더, `python3 tools/build_sprites.py`로 병합.
  3/4 탑뷰 정사영 카메라(바닥 1타일 = 32×24px, 2배 해상도 렌더). 규약은 `docs/asset-spec.md`.
- **힉스필드**: `docs/higgsfield-prompts.md`의 파일명대로 `assets/hf/`에 넣고 `python3 tools/build_sprites.py` 실행 → 자동 적용.
  초상화는 2D 애니메이션풍(미소녀·미소년) 표정별 19장. 초록 배경으로 만들었다면 먼저 `python3 tools/hf_key.py assets/hf/<파일>`.
  표정 초상화가 없으면 그 인물의 기본 초상화 → Blender 초상화 순으로 대체, CG가 없으면 건너뜀.

## QA 자동화

```bash
node tests/run-all.mjs     # 또는 npm test (Playwright + Chromium 필요)
```

| 스위트 | 내용 |
|---|---|
| `gating.mjs` | 잠긴 문이 구역을 실제로 막는지(BFS), 모든 조사 지점이 실제 조사 판정(바라보는 방향·조건식)으로 선택되는지 |
| `assets.mjs` | 1장에서 그려질 수 있는 모든 스프라이트 키 존재 여부 |
| `mobile.mjs` | 뷰포트·CSS·이벤트 차단, 롱프레스·핀치, **실제 터치(위치 판정)로 대사·조이스틱·버튼·메뉴 조작**, 앱 전환·가로 화면 일시정지 |
| `pad.mjs` | 가짜 게임패드 주입 → 타이틀·대사·이동·달리기·휴대폰 메뉴·선택지·키패드·연타를 패드로 조작, 키보드 방향키/Enter/Esc, 터치 복귀 시 화면 버튼 복원 |
| `janitor.mjs` | 순찰·발견·추격·타격·소음·라이터 시야·벽 차단·숨기 |
| `save.mjs` | 저장(사인펜 소모, 제한시간 중 거부)·실제 터치로 이어하기·복원·게임오버 후 복귀 |
| `playthrough.mjs [B\|A]` | 봇이 실제 입력으로 1장 오프닝→결계문 완주 (수위 정지 상태). 모든 대사·선택지·문서가 화면 최상단에 보이는지도 검사 |

헤드리스 Chromium으로는 iOS Safari 고유 동작(`-webkit-touch-callout`, 제스처 이벤트)을 직접 확인할 수 없으므로, 실기기 확인 항목은 `docs/qa-checklist.md`에 따로 정리했습니다.
